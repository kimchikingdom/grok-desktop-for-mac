## 수정됨

### 1. 치명·높은 동작

- [x] 1.1 `/`+Enter가 `/new`를 실행하지 않음. 키보드는 명령을 입력창에만 넣고, 로컬 명령은 클릭하거나 `/new`를 보낸 뒤에만 실행
- [x] 1.2 `ingest`가 다른 `sessionId` 이벤트를 버림
- [x] 1.3 `session:prompt`를 await. 실패 시 낙관적 말풍선 제거. `running`을 prompt 시작 즉시 설정
- [x] 1.4 다시 생성은 마지막 사용자 턴 이후를 지우고 `regenerate: true`로 재요청
- [x] 1.5 폴더 경고 확인을 메인 화면 모달로 표시. 최근 목록의 warn도 확인
- [x] 1.6 칩은 보낸 뒤 꺼짐 (한 턴만)
- [x] 1.7 받아쓰기는 중간 결과를 덮어씀. 없으면 버튼 숨김. 언마운트 시 stop
- [x] 1.8 삭제 시 화면을 먼저 비우고 앱 확인 대화상자를 씀
- [x] 1.9 초안은 세션별로 저장. 첨부는 전환 시 비움. 새 대화는 초안이 있으면 확인
- [x] 1.10 `dispose`가 이미 끝난 프로세스에서도 끝남. 타임아웃 레이스 추가

### 2. 보안

- [x] 2.1 민감 파일 그랜트는 경로 단위. 합성 승인은 세션 허용을 안 줌. 읽기 승인이 writeAllowance를 채우지 않음
- [x] 2.2 `bash -c` / `python -c` / `npm run deploy`는 alwaysAsk. 실행 세션 키는 바이너리 이름
- [x] 2.3 `media` 권한 자동 허용 제거
- [x] 2.4 `confirmedPath`는 방금 경고한 폴더와 일치할 때만 허용
- [x] 2.5 `diff:get`에 `resolveWithinRoot`
- [x] 2.6 Ask/Plan에서 fetch/other 자동 거부
- [x] 큰 파일은 2MB까지 읽음
- [x] 로그 파일 mode 0600
- [x] 민감 파일은 트리에서 첨부 버튼이 없음. prompt도 민감 첨부 무시
- [x] Trusted의 일반 쓰기는 추가 승인 없이 진행 (스냅샷은 유지)

### 3. GUI/UX

- [x] 헤더: macOS에서만 왼쪽 여백. 좁은 창에서 사용량·도움말 숨김. 모델 select 축소
- [x] 알림은 타이틀바를 밀지 않는 토스트. 종류별 색. 4초 후 닫힘
- [x] 검색창은 탭 위에 항상 있음. 파일 클릭=미리보기, +=첨부. 되돌리기는 항상 보임
- [x] 칩 한국어, `IconPlus`/`IconGear`/`IconTrash`. 드롭 시 테두리. `@`는 빈 접두어도 목록
- [x] 모드 라벨 질문/계획/에이전트. Think 접두어 한국어
- [x] 설정은 폴더 없이도 열림. Escape, aria-modal. 확인 대화상자는 앱 모달
- [x] 빈 화면 여백 축소. 스트리밍 중 하단 따라감. 위로 올리면 따라가지 않음
- [x] 사용량은 “이번 세션 N턴 · 창 크기”로 표시
- [x] diff 패널 너비 `min(380px, 36vw)`
- [x] 승인 대기 안내. 트레이에서 승인 대기도 취소 가능. 승인 중 모델 변경 잠금. 파킹 시 permission-resolved 이벤트

## 아직 남은 것 (이 패치에서 안 한 이유)

의도적으로 앱 범위 밖이거나, 인증서/별도 인프라가 필요함.

| 항목 | 이유 |
|---|---|
| grok.com 대화/Projects 동기화, Drive, 팀 | 비공개 웹 API / 명세 비목표 |
| Imagine Agent 캔버스, 영상 이어붙이기 | 웹 전용 제품 |
| Grok Voice 양방향 통화 | CLI/ACP에 없음. 받아쓰기만 |
| X 연동, Companions | 웹 전용 |
| 코드 서명·공증 | Developer ID 인증서 필요 |
| Playwright UI E2E | 새 테스트 스택. 세션 매니저 e2e는 유지 |
| 긴 대화 가상 스크롤 | 스크롤 따라가기는 넣음. 가상 리스트는 별도 작업 |
| Git 저장소 초기화 | 코드 수정과 별개. 원하면 `git init` |
| CLI 자체 쓰기의 스냅샷/되돌리기 | Git 목록으로 보완. 스냅샷은 `fs/write` 경로만 |
| 종료 코드/타임아웃 숫자 | ACP 이벤트에 안정적인 필드가 없음 |

단위 93, 보안 23, 승인 e2e 5개 통과 기준으로 위 수정분을 검증했다.

대화 지속성 계획 이행 이후의 잔여는 [docs/UNIMPLEMENTED.md](UNIMPLEMENTED.md)에 따로 정리했다.

## 2026-08-14 UI/UX 재점검

기능을 얹으면서 헤더·사이드바가 자주 쓰는 흐름을 가렸다. 아래는 이 패치에서 고친 항목과, 의도적으로 남긴 항목이다.

### 고침

- 사이드바 맨 위는 새 대화. 분기·원본 로그는 `이 대화` 아래로 내림. 워크트리 적용은 배너
- 대화 검색은 대화 탭에서만. ⌘K는 대화 탭으로 옮긴 뒤 검색창을 연다
- 헤더에서 보기 밀도를 빼고 대화 위쪽으로 옮김. 리뷰 버튼은 토글
- Esc는 확인·설정·단축키·미리보기·리뷰를 먼저 닫고, 닫을 것이 없을 때만 실행을 중단
- 슬래시/멘션 목록이나 세션 이름 편집 중 Esc는 그 입력만 취소
- 리뷰와 파일 미리보기는 동시에 열리지 않음. 쓰이지 않던 스냅샷 디프 패널 제거
- 변경 탭이 비어 있어도 리뷰 입구를 둠. ⌘S는 미리보기 저장
- 세션 상태·리뷰 범위·스테이징·작업 상태·샌드박스를 한국어로
- 위로 스크롤하면 `최신으로`가 나타남

### 남김

| 항목 | 이유 |
|---|---|
| 긴 대화 가상 스크롤 | 렌더러 재설계. 따라가기·최신으로로 우선 보완 |
| 파일 트리 검색 | 대화 검색과 별개. `@` 첨부 검색은 있음 |
| 좁은 창에서 리뷰+채팅 동시 배치 | 리뷰 너비만 줄임. 사이드바를 접는 건 다음 작업 |
| 푸시·PR·터미널·localhost 미리보기 | 제품 범위. UNIMPLEMENTED |
| 터치에서 말풍선 액션 | 데스크톱 우선. 호버 시 더 선명하게만 처리 |
